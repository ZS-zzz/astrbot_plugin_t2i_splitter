# astrbot_plugin_t2i_splitter

> 文本转图片 · 智能分段融合插件 —— 让 AstrBot 的回复变成一张好看的图片卡片。
> 💡 **本插件由 [DeepSeek](https://www.deepseek.com/) 制作。**

## ✨ 特性

- **完整 Markdown 渲染**：标题、粗体、斜体、粗斜体、行内代码、代码块、删除线、链接、有序/无序列表、引用、表格、分割线、转义字符
- **智能分段**：可选分段模式（默认单图，直接渲染原文，完整保留 Markdown 结构）
- **玻璃拟态卡片**：毛玻璃背景 + 圆角卡片 + 柔和阴影
- **每日一言**：自动从多个 API 拉取，30 分钟刷新一次，失败时用本地兜底句子
- **服务器状态**：CPU / 内存 / 磁盘 / 系统信息 / 运行时长（简洁 or 详细模式）
- **深浅色主题**：可自动根据时间切换，也可强制指定
- **随机 ACG 背景**：自动从网络拉取，失败时用程序化渐变背景
- **官方 QQ 机器人适配**：超过 4MB 时自动降级为 JPEG 并逐级压缩
- **非 LLM 文本转图**：可选开启，让工具返回、插件反馈等也转成图片

## 📦 安装

1. 将插件目录放入 AstrBot 的 `data/plugins/` 下
2. 安装依赖：

```bash
pip install -r requirements.txt
