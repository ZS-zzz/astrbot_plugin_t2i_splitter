# 文本转图片与智能分段插件 (astrbot_plugin_t2i_splitter)

将 AstrBot 中大语言模型输出的长文本智能分段，并转换为带有精美背景、毛玻璃质感的卡片图片。支持单图/多图模式切换，底部附带每日一言与服务器状态显示。

> 💡 **本插件由 [DeepSeek](https://www.deepseek.com/) 制作。**

## ✨ 功能特性

- **智能分段**：基于标点符号、换行符智能分段，支持 Markdown 表格、代码块保护，支持中英文混排保护。
- **两种图片输出模式**：
  - **多图分段**：按句分段，每段分别渲染成图片发送，带有人性化的自然延迟。
  - **单图保留分句**：将所有分段合并为一张长图（保留段落间距），适合不想被多张图刷屏的场景。
- **每日一言**：底部集成每日一言卡片，自动刷新缓存，支持 API 请求失败时的内置文案兜底。
- **服务器状态**：底部显示服务器状态卡片，支持“简洁”和“详细”两种展示模式（需安装 `psutil`）。
- **极简中文配置**：从 v1.3.0 起，后台配置面板全面中文化，仅保留 10 个核心自定义项，无需繁琐配置。
- **动态高度计算**：修复了卡片的错位重叠问题，无论一言文本多长，都能精准计算高度，自动排版。
- **主题自适应**：支持浅色/深色主题自动切换，带有毛玻璃半透明背景效果。

## 📦 安装方法

1. 将本插件文件夹 `astrbot_plugin_t2i_splitter` 放入 AstrBot 的 `data/plugins/` 目录下。
2. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
   > 如果你的运行环境中没有 `psutil`，插件仍可正常使用，但服务器状态卡片将提示未安装。
3. 重启 AstrBot 或在插件管理面板重载插件。

## ⚙️ 配置说明

在 AstrBot 后台插件配置面板中，你可以看到以下中文配置项：

| 配置项 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| 卡片宽度 | 整数 | 1000 | 生成图片的基础宽度（像素） |
| 字体大小 | 整数 | 28 | 正文内容的字体大小 |
| 主题模式 | 下拉选择 | 自动 | 可选：自动 / 浅色 / 深色 |
| 品牌名称 | 字符串 | 无名小服 | 左上角显示的品牌名称 |
| 显示头部 | 布尔 | 开 | 是否显示头部信息（品牌名、时间、日期等） |
| 显示每日一言 | 布尔 | 开 | 是否在中间显示每日一言卡片 |
| 显示服务器状态 | 布尔 | 开 | 是否在最底部显示服务器状态卡片 |
| 状态详细程度 | 下拉选择 | 简洁 | 可选：简洁 / 详细 |
| 图片转换方式 | 下拉选择 | 多图分段 | 可选：多图分段 / 单图保留分句 |
| 最大分段数 | 整数 | 5 | 智能分段时最多允许分成几句（仅在多图分段模式下生效） |

## 🛠️ 指令说明

- `/t2i [文本]`：测试指令，将输入的文本直接转换为图片，用于快速预览渲染效果。

## 📝 更新日志

### v1.3.0
- **修复**：彻底修复了因一言文字过长导致与下方服务器状态卡片重叠错位的问题（改为动态高度计算）。
- **优化**：配置面板极简中文化，仅保留 10 个核心配置项，降低使用门槛。
- **新增**：支持“单图保留分句”模式，所有回答只转一张图片但保留段落间距。
- **新增**：新增服务器状态显示，并支持简洁/详细两种程度切换。

### v1.2.0
- 增加图片转换方式选项（多图分段 / 单图保留分句）。
- 增加服务器状态显示（支持详细/简洁模式）。

### v1.0.0
- 初始版本，文本转图片，智能分段。
